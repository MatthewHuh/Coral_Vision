A Python-based computer vision tool designed to automatically detect, segment, and calculate the pixel area of coral fragments from overhead grid images.

This project tackles the specific challenge of isolating coral fragments from a complex background containing water, white placement cards, and a massive continuous black grid structure. It utilizes OpenCV and offers multiple segmentation strategies to find the most accurate contours.

1. run: pip install -r requirements.txt
2. Uncomment the method you want to use in coral_vision.py
3. run: python coral_vision.py
